# Decision records

Each record explains one decision that shapes this site: the context, what was chosen and what follows from it. Records are not edited after they are accepted; a new record supersedes an old one.

| Record                           | Decision                                                  |
| -------------------------------- | --------------------------------------------------------- |
| [0001](0001-ask-my-portfolio.md) | Ask my portfolio answers only from the repositories' docs |

New records copy the shape of 0001: a numbered file `NNNN-short-title.md` with **Status**, Context, Decision and Consequences. Files matching `docs/adr/0*.md` are indexed for Ask my portfolio, so write them for a reader who has not seen the code.
